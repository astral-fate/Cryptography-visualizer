DES VISUALIZER

The DES Encryption algorithm (also known as Data Encryption Standard) is a symmetric block cipher algorithm with a block/chunk size of 64 bits.
It converts these individual blocks using key of 56 bits. Once it encrypts these blocks, it joins them together to form the ciphertext.


To understand the way DES works, you first need to learn how it transmits information between multiple steps.
Since a single block is 54 bytes, a 4x4 matrix holds the data in a single block, with each cell holding a single byte of information.
